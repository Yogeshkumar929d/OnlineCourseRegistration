# Online Course Registration System

Simple BCA college project based on BCA-64T-213: Object Oriented Concepts Using Java Programming.

## Technologies
- Java 17
- JSP
- Servlet
- JDBC
- MySQL
- HTML/CSS
- Apache Tomcat 10+

## Features
- Student Registration
- Student Login
- View Courses
- Register for a Course
- View My Courses
- Logout

## Setup
1. Install JDK 17, MySQL and Tomcat 10+.
2. Run `database.sql` in MySQL.
3. Open `src/main/java/DBConnection.java`.
4. Change MySQL username/password.
5. Compile and deploy the project on Tomcat.
6. Open `http://localhost:8080/OnlineCourseRegistration/`

## Syllabus Covered
- Classes and Objects
- Encapsulation
- Inheritance
- Method Overriding
- Constructors
- Arrays / Strings
- if-else and loops
- Exception Handling
- JSP
- Servlet life cycle
- JDBC connectivity
